# 2. ## Tracks baby's nap, feeding, diaper, and burp


# 3. #### Description:

#### This project comes with two files project.py and test_project.py. With project.py we find four functions. At the very top we have main and this function runs the entire program. Then we have validate_date that return a datetime object if valid if not, returns None. The next file, log_event appends one timestamped event to the csv file. Last we have view_log that prints every logged event.

##### Welcome to baby tracker. This fun app allows every parent to keep track of four essential events that happen in every day life for a baby. It keeps track of sleep when it starts and ends. As well as feeding, diaper change and when the baby burps. To run this program you first need to type in on your terminal window python project.py. You'll then be presented with the date and a list of options. Each option when selected will keep track of the event you want to record. The design behind the program was based on practicality. Let's go over on some of these design features. For example the date was built inside a loop on its own so that way, only once during each session you'll be asked to type in today's date. This will allow the parent to know exactly what day the baby had his/her activities. Another neat design feature is our view_log option. That allows for the parent to view the log history. This will ensure to tell the parent exactly when was for example a baby's last meal. As a parent you need help more than anything and the design was influenced on that very same principle.
